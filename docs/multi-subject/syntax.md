## content chemical-formula

化学式の元素記号・添字・電荷を立体のコピー可能な文字で組む。

| Property | Type | Required | Default |
| --- | --- | --- | --- |
| formula | string | yes | — |
| caption | string | no | "" |

### minimal

```content chemical-formula
formula: H2O
```

### standard

```content chemical-formula
formula: SO4^2-
caption: 硫酸イオン
```

Restrictions:

- {{chemical-formula:H2O}}のインライン表現も同じ定義を利用する。
- Fe3+は単原子の3価、NH4+はNH4の1価。多価の複合イオンはSO4^2-のように^を明示する。
- 同位体・任意マクロ・化学式からの構造推定は未対応。

Invalid example:

```text
formula: Xx2O
```

## content chemical-reaction

係数・状態・反応矢印・上下条件を持つ反応式。元素数と電荷だけを照合する。

| Property | Type | Required | Default |
| --- | --- | --- | --- |
| reactants | array | yes | — |
| products | array | yes | — |
| arrow | string | no | "forward" |
| above | string | no | "" |
| below | string | no | "" |
| caption | string | no | "" |

### minimal

```content chemical-reaction
reactants:
  - formula: H2
    coefficient: 2
  - formula: O2
products:
  - formula: H2O
    coefficient: 2
```

### standard

```content chemical-reaction
reactants:
  - formula: N2
    state: g
  - formula: H2
    coefficient: 3
    state: g
products:
  - formula: NH3
    coefficient: 2
    state: g
arrow: equilibrium
above: Fe触媒
below: 加熱・加圧
caption: アンモニア合成の表示例
```

Restrictions:

- 釣り合っていても反応が実際に起こることを保証しない。
- 式は自動補正しない。不一致はQA warning。
- 非常に多い反応物は横幅が不足するため、原稿側で意味を保つ段階分割が必要。

Invalid example:

```text
reactants:
  - formula: Xx
products:
  - formula: H2O
```

### minimal

```figure chemical-structure

```

### standard

```figure chemical-structure
caption: エタノールの明示構造
atoms:
  - id: C1
    element: C
    hydrogens: 3
    position: [140, 130]
  - id: C2
    element: C
    hydrogens: 2
    position: [290, 130]
  - id: O
    element: O
```

## figure circuit-diagram

接続IDと描画座標を分離した回路図。

| Property | Type | Required | Default |
| --- | --- | --- | --- |
| width | number | no | 640 |
| height | number | no | 360 |
| caption | string | no | "" |
| nodes | array | yes | — |
| wires | array | no | [] |
| components | array | no | [] |

### minimal

```figure circuit-diagram
nodes:
  - id: A
    position: [100, 120]
  - id: B
    position: [400, 120]
components:
  - id: R
    kind: resistor
    from: A
    to: B
    label: R
```

### standard

```figure circuit-diagram
caption: 抵抗と電源の回路
nodes:
  - id: A
    position: [100, 100]
  - id: B
    position: [500, 100]
  - id: C
    position: [500, 260]
  - id: D
    position: [100, 260]
components:
  - id: R
    kind: resistor
    from: A
    to: B
    label: R
  - id: E
    kind: battery
    from: D
    to: C
    label: E
wires:
  - from: A
    to: D
  - from: B
    to: C
```

Restrictions:

- nodes.idを端子として部品・wireの接続を明示する。交差したwireを勝手に接続しない。
- 部品は両端の中点に描画する。接続点間は60px以上を推奨。
- 電圧・電流・回路動作は推論しない。

Invalid example:

```text
nodes: []
components:
  - id: R
    kind: resistor
    from: missing
    to: B
```

### minimal

```figure image-annotation
id: cell-view
assetId: cell

  - id: nucleus
    kind: numbered-marker
    position: [0.5, 0.5]
    number: 1
```

### standard

```figure image-annotation
id: cell-view
assetId: cell
caption: 元画像と注釈レイヤー
annotations:
  - id: nucleus
    kind: numbered-marker
    position: [0.52, 0.46]
    number: 1
    label: 核
  - id: arrow-to-nucleus
    kind: arrow
    position: [0.2, 0.2]
    end: [0.5, 0.45]
    label: 注目する位置
```

Restrictions:

- position/endは画像左上を(0,0)、右下を(1,1)とする。radiusは短辺割合。labelOffsetはSVG内部px。
- 表示レベルはnone/numbered/detailed。元画像を直接変更しない。
- 図・注釈の参照はID。表示文字や丸数字を参照キーにしない。
- 注釈付き画像は縦横比1:8〜8:1。極端な縦長/横長資料はimage-assetで配置する。

Invalid example:

```text
id: bad
assetId: cell
annotations:
  - id: A
    kind: arrow
    position: [1.2, 0.5]
```

## content reading-passage

段落・文・範囲IDを持つ改ページ可能な読解長文。

| Property | Type | Required | Default |
| --- | --- | --- | --- |
| id | string | yes | — |
| title | string | no | "" |
| paragraphs | array | yes | — |
| sentenceNumbers | boolean | no | true |
| paragraphNumbers | boolean | no | true |
| lineNumbers | boolean | no | false |
| annotationPresentation | string | no | "legend" |
| annotationLabelSize | number | no | 8.5 |
| levels | object | no | {} |
| vocabulary | array | no | [] |
| vocabularyPlacement | string | no | "passage-end" |
| notes | array | no | [] |

### minimal

```content reading-passage
id: passage1
paragraphs:
  - id: p1
    sentences:
      - id: s1
        originalText: Learning takes time.
```

### standard

```content reading-passage
id: passage1
title: Learning Together
lineNumbers: true
paragraphs:
  - id: p1
    sentences:
      - id: s1
        originalText: Students read books.
        annotations:
          - id: A
            start: 14
            end: 19
            role: O
            label: 下線部A
vocabulary:
  - word: books
    meaning: 本
    target:
      passageId: passage1
      paragraphId: p1
      sentenceId: s1
      spanId: A
```

Restrictions:

- 長文全体をatomicにしない。文番号は原文外、行番号はTypst par.lineの余白要素。
- 各文のfunctionGroupsで名詞〈〉・形容詞〔〕・副詞()を指定する。原文と範囲は変更せず、plainでは非表示。交差・同範囲・不正範囲はエラー。
- annotationPresentation: stacked は全役割を英文の下に表示し、内側を英文の直下、外側をその下に置く。annotationLabelSizeは7〜11pt、既定8.5pt（stacked専用）。
- stackedは段落と本文の順を保ち、長句を実測した幅に応じて語境界で折り返す。文全体のカード化・縮小・1頁への固定はしない。既存のlegend/interlinear/hierarchy/adaptiveも保持。
- 文番号は長文内の通し番号、Sentenceの参照表示は段落内番号。
- 行番号は印刷レイアウトで変動するため、設問の永続参照にはIDを使う。
- 語注の対象はIDで指定。段落末または長文末へ配置する。

Invalid example:

```text
id: p
paragraphs:
  - id: first
    sentences: []
```

## content syntax-annotation

原文とコードポイント範囲・役割・親子/修飾関係を分離した英文注釈。

| Property | Type | Required | Default |
| --- | --- | --- | --- |
| id | string | yes | — |
| originalText | string | yes | — |
| annotations | array | no | [] |
| functionGroups | array | no | [] |
| presentation | string | no | "legend" |
| visualStyle | string | no | "classic" |
| levels | object | no | {} |

### minimal

```content syntax-annotation
id: greeting
originalText: Hello, world.
```

### standard

```content syntax-annotation
id: svo
originalText: Students read books.
annotations:
  - id: subject
    start: 0
    end: 8
    role: S
  - id: verb
    start: 9
    end: 13
    role: V
  - id: object
    start: 14
    end: 19
    role: O
```

Restrictions:

- start/end は0始まり、Unicodeコードポイント、endは範囲に含まない。UTF-16の添字ではない。
- 原文はplain text。装飾はannotationsに指定し、Markdownの記号を文字数へ混在させない。
- functionGroups は任意の独立した機能注釈。id/start/end/function（noun・adjective・adverb）を指定し、〈〉・〔〕・()を原文の範囲に対応して表示する。文法機能の推定はしない。
- functionGroups の範囲は離すか完全な入れ子にする。同一範囲・交差・不正範囲はエラー。plain では記号やIDを出力しない。未指定/空配列は従来出力と同一。
- S/V等は指定済みの情報のみ。minimal は下線と主要役割凡例、detailed は上線・括弧線・関係・noteも表示。
- 重なる範囲は装飾を合成する。弧状の依存矢印ではなく、対象IDと範囲を併記した関係凡例を使う。
- visualStyle: soft-highlight はinterlinear専用のBデザイン。淡色背景・役割バッジ・機能括弧を使い、装飾縦線/上線は描かない。plainとclassicは従来同一。長い範囲は実測語境界で折り返す。
- presentation: interlinear は原文直下に役割を配置する任意表示。未指定/legend は従来表示のまま。plain に注釈は出さない。
- interlinear は重複・入れ子・注釈内改行、または実測で行幅を超える区間では全情報を保持した凡例へ切り替える。schema警告とTypst metadata(kind: syntax-annotation-layout)で検出可能。関係は指定済みの対象役割・対象語を表示し、推定しない。

Invalid example:

```text
id: bad
originalText: I run.
annotations:
  - id: V
    start: 9
    end: 20
    role: V
```

## content translation-pair

英文・和訳・語注・補足・番号を段落単位で近接させる対訳。

| Property | Type | Required | Default |
| --- | --- | --- | --- |
| pairs | array | yes | — |

### minimal

```content translation-pair
pairs:
  - id: p1
    originalText: I like music.
    translation: 私は音楽が好きです。
```

### standard

```content translation-pair
pairs:
  - id: p1
    number: Paragraph 1
    originalText: A well-known student said, "Don't give up."
    translation: よく知られた生徒は「諦めないで」と言った。
    vocabulary:
      - word: give up
        meaning: 諦める
    note: ハイフンと引用符を保つ。
```

Restrictions:

- 2列の高さ合わせをしない。短文対は近接保持、長文対は自然に改ページ。
- pairs 内の原文は一度だけ保持。文法推定・翻訳生成はしない。

Invalid example:

```text
pairs:
  - id: p1
    originalText: Hello.
```
